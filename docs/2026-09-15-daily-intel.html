LLM / Frontier Models

AI Agent / Agentic Workflow

Agent 的控制面出现两种形态：一是软件工厂的隔离分支、证据站和 review gate；二是 `@levelsio` 的 Nomads MCP 示例，让 Agent 读取邮件并写回旅行资料。前者缺少可靠性数据，后者缺少授权和错误恢复证据；二者共同提示“能调用工具”不等于可以无监督修改长期状态。

AI Coding / Developer Tools

@frxiaobei 的 Git AI 线索把 coding agent 的观测对象从产出量扩展到成本、生产采用和返工；Claude Code v2.1.269 的 plugin eval则把可重复评分和 HTML/JSON 报告做成命令。Simon Willison 的 commit-rewriter 0.1 正文展示了把 Agent 生成的提交信息清理成可公开历史的本地工具；Quoting Laurie Voss则把“代码成本下降后，定义需求、审查、修复和运营成为主要工作”的判断留作工程组织背景。这些信号支持“代码生成后还要有可审计整理和评测”，但不代表通用质量已解决。

AI Governance / Public Legitimacy
