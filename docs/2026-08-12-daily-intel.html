AnthropicAI 的 direct-x 推文 引出官方研究 Learning more about Claude's mathematical capabilities。正文说，未公开研究版本的 Claude 没有解决黎曼猜想，但在既有数学工作的基础上，把满足相关条件的零点比例已知下界从 41.6% 提到 67.2%；Anthropic 数学家检查了论文，并给出可形式验证的证明。研究过程使用两个 Claude Code 会话、约 3100 万输出 token、60 个子代理和大量数值/反例检查，原文已归档为 本地正文本地证据。这是 official-source + direct-x 组合证据，结论仍需独立数学家复核，不能写成“AI 证明了黎曼猜想”。
