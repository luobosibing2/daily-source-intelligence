## 归档规则

- 每个重要条目仍使用独立子目录，并保留 `raw/` 和 `docs/`。
- `raw/` 保存官方原文、RSS/JSON 发现记录、README 快照或辅助提取文件。
- `docs/` 保存结构化研究笔记，必须说明它来自哪天 daily source、对应哪些趋势、证据等级与不确定性。
- 新增或改名重要条目时，同步更新本索引。
